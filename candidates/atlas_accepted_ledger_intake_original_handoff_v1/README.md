Neither path is an employee seat or a duplicate Work engine. Both still require independently verified owner/worker source authority, original Work, exact Ledger, no competing responsibility, and no pending offer.
- Accepted standing-scope writer can assign a native canonical Person with **already accepted matching native Person scope** and no old employee seat; the existing writer continues to enforce exact scope/ledger and already allocated/outstanding offer checks.
- **Important:** `offer_unallocated_company_work_self_api_v1` still requires exactly one **active institutional Organization membership** for its recipient. That legacy-style offer must **not** be used for native-only Katie/Anna-like People. Instead the **already existing native exact-Work path** is source-adapted here: `propose_native_ledger_exact_work_scope_owner_self_api_v1` → independent worker consent via unchanged `respond_native_ledger_standing_scope_self_api_v1` → existing `assign_native_ledger_company_work_under_scope_owner_self_api_v1`. Do not fabricate membership, silently allocate at review time, or imply that signed recipient Today is already proven.
