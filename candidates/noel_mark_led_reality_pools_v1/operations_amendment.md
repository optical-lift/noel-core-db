# Proposed amendment to `docs/NOEL_RESEARCH_OPERATIONS.md`

**Status:** draft documentation change for repository review; not applied to repository.

Current step 3 says to verify “witness, token ID, canonical reference, surface, and Strong's lexical identity.” Retain the source verification duty, but make Strong’s secondary:

> 3. Begin with the observed writing at its declared representation rank and versioned Noel Mark Identity (NMI). Verify the witness, original exact written form (NMF), source-token occurrence ID, canonical coordinates and source provenance. A versioned consonantal comparison identity is an R2 derived lookup key, not proof of physical R0 marks or identical function. Strong's, inherited governance IDs, lemmas, morphology, and modern glosses are downstream historical annotations; record them when present, but neither require a Strong's number to admit a mark nor allow Strong's to split, merge, or ratify mark identities.

Current step 2 says to identify an existing founder pool and Strong's alias. Extend it:

> 2. Resolve the NMI first; inspect all admitted NMF forms and source occurrences and the current pool-identity links. If one or more legacy Reality Pools are associated, preserve every existing `node_id`, authority state, definition, note and source anchor. Where multiple founder pools correspond to one mark, create proposed reconciliation evidence; do not merge records or promote one to authoritative without a recorded steward decision. If no mark-first record exists because the registry is not yet deployed or the language profile is unsupported, use the current legacy lookup explicitly as a compatibility path, not as mark authority.

Add to the **Protection** section:

>  - Identity and functional equivalence are separate decisions. A common mark-level comparison identity may contain contrary or divergent canonical operations. Any acceptance of one governing lexical pool per NMI requires source-backed review, an explicit steward decision, and durable links to every superseded or historical pool.
>  - Strong's label evidence is many-to-many with mark identities and potentially with functional pools. The legacy `draft.noel_reality_aliases` unique mapping is compatibility metadata only and is not allowed to control the mark-first reader.
>  - Original-language profiles are independent. The Hebrew R2 comparison contract does not silently govern Greek, Aramaic, or R0/R1 physical manuscript marks.

No other steps, founder definitions, permissions, or deployment rules should be changed by this amendment.
