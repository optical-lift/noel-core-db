## U2F 02 — native Ledger/Person/seat identity, separate from authorization

`02_native_ledger_carrier_identity_held.sql` is **a private, read-only source candidate** that checks one existing delegated authorization against its registered active carrier, an active native `ledger.ledgers` record, an exact active native `ledger.seats` seat held by the authorization's active canonical Principal/Person, and nonrevoked current authorization dates. It takes only two known UUIDs and returns **identity status without returning any private identity, credential or other records**. It never grants Work authority, root authority, accepted-offer proof, Rulebook/Need proof or actual Work; the JSON response explicitly says each is false, even if `identityAligned=true`. The function is `STABLE SECURITY INVOKER`, not a public API, and all EXECUTE is revoked from `PUBLIC`, `anon`, `authenticated` and `service_role`. No new table or old Task/queue/Farm/legacy-Ledger object is referenced by this source.

**Why this narrow check matters:** the installed generic `atlas.evaluate_delegated_agent_command_authority_v1` validates a Principal's existing `atlas.principal_has_ledger_authority_v1` and optional seat. That source's current installed definition checks `atlas.principal_ledger_authorities` and `atlas.ledgers`, whereas genuine U2C original approval uses both the current signed human Principal and active `ledger.ledgers` plus native seat. The legacy-surface root authority remains an independent *source-adjudication and retirement* question. The new private helper does **not** pretend a native seat by itself is a governing root, and it does not modify the installed generic evaluator. It is a source input for later independent U2F actor authority, not its replacement.

The operative gate remains held: **no canonical Work before fresh owner/Rulebook/Need, independently accepted recipient offer, valid currently authorized nonhuman delegated carrier/command, exact native governing Ledger, capacity and source-atomic one-original writer.** Existing live catalog has zero registered carriers and zero active authorizations, so no true positive U2F issuer can be claimed. Later source must disallow null/forged Principal and seat, stale or revoked authorization, mismatched Ledger or Person, and old legacy authority-only shortcuts. It must prove a native governing authority, not just the identity-alignment fact.

**Verification:** no-network source tests now cover the private identity function alongside the original draft-only command and reject direct old `atlas.ledgers` / `atlas.principal_ledger_authorities` / `atlas.tasks` / `atlas.task_release_queue_items` references in the identity helper.
