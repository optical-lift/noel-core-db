Installed `evaluate_delegated_agent_command_authority_v1(uuid,text,integer)` MD5 `28bbb95ce3874a7dbf641387c22ac1fd` explicitly rejects nonactive commands and checks the explicit allowlist plus execution class. **Critical identity boundary:** the generic agent authorization's `ledger_id` FK targets **`ledger.ledgers`**, while held [U2E campaign #2486](https://github.com/optical-lift/noel-core-db/pull/2486)'s `ledger_id` FK targets **`atlas.ledgers`**.
