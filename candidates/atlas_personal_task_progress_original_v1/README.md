# Original personal Task progress — SOURCE CANDIDATE ONLY

This candidate supplies the single missing **Write what happened** operation on an existing **personal dated task**. It does **not** create another task, assign Company Work, interpret a report as Done, or offer institutional Work result authority. The signed identity remains the same authenticated owner and active Principal who owns `atlas.task_entries`.

The source is two original-bound RPCs plus a private immutable progress-event ledger: append a 1–2000-character note under a stable UUID action, and read pages of original-linked progress newest-first with an exact timestamp/UUID cursor. An interrupted response may replay only the same exact original, Principal, action ID and note. The writer locks the original row before admitting any new note and rejects completed, archived, institutionalized, foreign, anonymous or revoked original-task ownership. Race with promotion uses the same row lock. The read writer never returns an organization roster, unrelated personal task, or all-person history. Permanent removal of the original removes its private progress via FK cascade; ordinary archive retains history.

**Functional boundary:** Notes are statements of recorded progress, not automatic task-state transitions. The existing signed personal Done/correction source still owns completion. Cancel, Blocked and Unable status/authority semantics are NOT implemented by this candidate; they are separate pending release requirements, not silently treated as Archive or progress writing. The institutional Work version continues using its native signed Result writer. The same Task Focus writing input can call the corresponding source adapter.

**Before any release:** source review; disposable full production-schema clone with postconditions; genuine separate local GoTrue sessions; first/second-owner/outsider/anonymous and revoked read and write denial; exact-action replay versus changed original/body conflict; completed/archived/transferred denial; old/new page cursor, one original Work-identity preservation, promotion race and original deletion private-history cleanup; governed migration source generation and separate protected database release. No direct production SQL or actual user/task mutation by this source PR. Atlas browser acceptance must verify that a personal note appears under the same original task with no full-page reload.

This is an explicit part of the **same approved universal Task Face release**, not a separate household, farm, or personal Work engine.
