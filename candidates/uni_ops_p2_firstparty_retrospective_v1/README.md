A selected existing original requires true native Rhythm/farm/Ledger relevance and **both** current Subject identity/condition disclosures; its created_at preceding the LOG timestamp is chronology only, never proof it preceded activity. Recheck unretracted unchanged first-party log and P1 collision at review. Any review is **not** physical Actual acceptance, establishment of an original, backdated consent or an entitlement to repeat.
- **`03_private_governor_case_history_held.sql`**: exact known report ID plus same current native governing Ledger root, bounded 25-entry keyset pagination; returns source log date, log-recorded time, worker *claimed* performance time, report-received time and review sequence, with the claims explicitly distinguished. No roster, worker contact data, raw report text or unconditionally disclosed linked original IDs. No Work/Result mutation.
- **`deferred_security_postconditions.sql`**: authored, **not run**, structural/trigger/ACL source check.
- **`DEFERRED_ACCEPTANCE.md`**: real-signature and negative-case collected acceptance matrix.

All three source implementations are private, `SECURITY DEFINER SET search_path TO ''`, with raw tables RLS/FORCE RLS and EXECUTE revoked from `PUBLIC, anon, authenticated, service_role`. A future approved public or scoped internal transport would require independently specified current actor permission, P1 collision protection and privacy tests. None is created here.
