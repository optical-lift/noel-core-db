# UNI-OPS-01 / P2 — first-party retrospective testimony and independent governor source review (HELD)

**2026-11-06**. New **separate** Noel source draft, not an installed migration. The governing November 4 Actual-first amendment says real activity reported without the necessary original must not be discarded or converted into fictional earlier assignment. The actual source report and report/review/original timestamps must stay distinct. A qualified Result/Done requires separately authorized source, and 6A prohibits automatic successor Work.

## Source-owned bounded outcome

- **`01_firstparty_activity_testimony_intake_held.sql`**: first-party `atlas.field_logs` source `worker_manual_log`, with source-`auth.uid()`, current `atlas.current_person_id_v1`, matching active `atlas.farm_memberships` and actual `atlas.farms.organization_id`. Rejects retracted logs and activities already recognized by the original P1 assigned-Actual link. Worker-submitted `p_reporter_claimed_performed_at` is an **unverified claim**; `field_logs.log_date`, `field_logs.created_at`, server `report_received_at`, claimed performance timestamp and any later Work/approval time are separately preserved. A digest binds the exact source sentence without copying private narrative. One append-only report per field log, exact replay and collision denial. A claimed existing original is only a claim; same native farm source is verified but no authorization is inferred. For a **known** pre-existing correctly allocated original, the writer refuses P2 and directs future work to P1. If no original was supplied, the absence of a claim is **not** a verified absence of an original. No invented Work/Need/Result.
- **`02_separate_governor_source_review_held.sql`**: independent authentic current governing Company Ledger root through `atlas.company_work_native_ledger_owner_self_v1`, real native `atlas.farm_crop_ledger_custody_v1` and `atlas.ledger_organization_participations`. Every decision is an append-only event with an action ID and expected previous review ID. Outcomes are limited to `needs_more_firstparty_source`, `historical_testimony_acknowledged_without_actual`, `existing_original_needs_separate_adjudication`, or `testimony_rejected`. A selected existing original requires true native Rhythm/farm/Ledger relevance and **both** current Subject identity/condition disclosures; its created_at preceding the LOG timestamp is chronology only, never proof it preceded activity. Recheck unretracted unchanged first-party log and P1 collision at review. Any review is **not** physical Actual acceptance, establishment of an original, backdated consent or an entitlement to repeat.
- **`03_private_governor_case_history_held.sql`**: exact known report ID plus same current native governing Ledger root, bounded 25-entry keyset pagination; returns source log date, log-recorded time, worker *claimed* performance time, report-received time and review sequence, with the claims explicitly distinguished. No roster, worker contact data, raw report text or unconditionally disclosed linked original IDs. No Work/Result mutation.
- **`deferred_security_postconditions.sql`**: authored, **not run**, structural/trigger/ACL source check.
- **`DEFERRED_ACCEPTANCE.md`**: real-signature and negative-case collected acceptance matrix.

All three source implementations are private, `SECURITY DEFINER SET search_path TO ''`, with raw tables RLS/FORCE RLS and EXECUTE revoked from `PUBLIC, anon, authenticated, service_role`. A future approved public or scoped internal transport would require independently specified current actor permission, P1 collision protection and privacy tests. None is created here.

## Important distinction from existing P1 historical sources

Noel P1 [#2487](https://github.com/optical-lift/noel-core-db/pull/2487), file `l1_l2_current_source_snapshot/16_historical_self_adoption_review_candidate.sql`, reviews a historical self-adoption **where an original Work and allocation already exist**. That is valid historical evidence, but **not P2 without an original**. P1's `01_assigned_activity_recognition_held.sql` recognizes a worker's Activity only against a pre-existing authorized, matching original with genuine physical typed Actual. P2 does neither; it archives honest testimony pending first-party source discovery and separate governor authority.
