Manager neither self-admits nor grants a Titus license.
3. **Recipient self-service:** Signed exact recipient sees only their pending invitation; manager and unrelated signed Person cannot inspect it. Recipient's own acceptance is separate from manager issuance; the private recipient-only inbox then lists an active admission, while the account selector recognizes the institution under **that same signed Person login**. 4. **Revocation and withdrawal:** Manager may withdraw only with current exact `withdraw` responsibility; recipient may self-withdraw. No user-editable metadata determines authority; no service-role bypass.
6. **Concurrency and custody:** Two concurrent acceptance attempts/competing invitations for one Person+Ledger cannot create two simultaneously active admitted contexts.
