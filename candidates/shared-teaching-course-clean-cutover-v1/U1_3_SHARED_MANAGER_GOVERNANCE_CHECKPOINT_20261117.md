# U1.3 — Shared institutional Titus manager governance (HELD)

**Bounded outcome:** An independently authorized **institutional root** can appoint, atomically transfer, or revoke a Titus university account manager through the already-governed Reality Person/Entity + exact Ledger authority model. This increment **does not create the root**. It does not merge, migrate or deploy anything; U1 remains open.

## Verified source and custody

- [Shared root-governed manager source candidate](./shared_titus_institution_manager_governance_candidate.sql) introduces the **held** private `titus.institution_account_manager_governance_v1` original ledger, immutable update/delete guard, exact current root guard and separately exposed authenticated command `public.shared_titus_institution_manager_command_self_api_v1`. Source class: **shared** because it writes the existing canonical `reality.responsibility_relations` original and ending state (not a duplicate Titus Person/organization ontology).
- **Root gate:** the current signed canonical Person must have exactly one current `reality.responsibility_relations` with `responsibility_key='titus_institution_account_root_governance'`, `jurisdiction_kind='entity'`, exact canonical institution Entity, exact `scope.ledgerId`, and the exact requested `appoint_manager`, `transfer_manager`, or `revoke_manager` operation. Existing `reality.resolve_responsibility_relation_v1` must independently return the same relation; check under `FOR SHARE`. A Ledger seat, institution membership, Auth login, platform pilot power, or Course role is NOT this authority.
- **Single-manager transaction:** serialize all manager commands on the exact `ledger.ledgers` row with `FOR UPDATE`. Appoint only when no active manager exists; transfer requires the one specific active manager and ends it in the same transaction as the new manager appointment; revoke ends only that manager. Reject ambiguous pre-existing manager standing and refuse to rewrite an unrecognized earlier original. Each new manager is an independently canonical Person and receives only `invite`/`withdraw`/`cancel` for this exact institution and Ledger; no login, Titus account admission, license, seat or Course right is created.
- **Immutable evidence:** every signed source mutation records an immutable governance original with unique (actor, request) receipt, original root, exact institution/Ledger, old and new manager and Reality responsibility IDs. Identical retry returns the original receipt; conflicting retry denies. The real Reality relation state remains governed by its existing `active/ended` state transition.
