  - `atlas.principal_authority_position_v1`

## Custody compatibility

The live database-custody workflow uses `public.shared_db_custody_release_packet_v1` for release verification rather than the now-internal `atlas.source_custody_release_packet_v1()`. Both hardening migrations have exact production/source Git blob parity.

This baseline is descriptive, not an allowlist. The clean Atlas rebuild should reduce and adjudicate this surface rather than preserving it automatically.
